How much should routing intelligence cost?

AxonLLM compares a local keyword-and-regex classifier, an LLM classifier, and a confidence-gated hybrid on the same labeled prompts. The benchmark isolates the routing decision so generation latency and downstream model spend cannot hide the router's own cost.

Regex improvement

54.2% → 98.6% on the regression corpus

Boundary-aware matching, requested-intent patterns, quote masking, weak-evidence thresholds, and explicit negation handling fixed both missing intents and topic-word collisions.

Missing intent phrases

Rules now recognize actions such as “compare and contrast,” “condense,” “extract central claims,” “compose a sonnet,” and “find eigenvalues.”

Topic-word collisions

A single word such as “Python,” “algorithm,” or “creative” no longer overrides the requested operation. Quoted material is treated as referenced content.

Negated operations

“Executive overview, not code changes” and “derive the expected value; do not write a story” route by the requested task rather than the rejected one.

Interpretation

What this experiment supports

01

Start deterministic

For a stable taxonomy, a reviewed local classifier can be fast, cheap, explainable, and accurate enough to make an LLM router unnecessary.

02

Escalate uncertainty, not every prompt

Hybrid routing reduced LLM calls to 16.7%, but its tail latency and cost remained visible—and one LLM escalation changed a correct general route into an incorrect creative route.

03

Benchmark your workload

A rule set can overfit a known corpus. Freeze an unseen sample from the target workload, review its labels, and compare downstream savings before production rollout.

Methodology

Reproducible, with the caveats attached

Every prompt is evaluated against the same six-label taxonomy. Router cache reuse is disabled with a per-request nonce, and direct router token cost is calculated from recorded usage.

# Compare against any OpenAI-compatible router endpoint
uv run --locked axon-benchmark-routing \
  --strategy heuristic \
  --strategy llm \
  --strategy hybrid \
  --hybrid-threshold 0.3 \
  --llm-base-url http://127.0.0.1:8001/v1 \
  --llm-model groq-gpt-oss-20b \
  --llm-api-key-env AXON_BENCHMARK_API_KEY \
  --llm-input-cost-per-million 0.075 \
  --llm-output-cost-per-million 0.30
  • The improved heuristic was tuned against this corpus, so 98.6% is a regression score rather than held-out evidence.
  • One repetition captures a reproducible snapshot, not a confidence interval. Provider latency and stochastic classification can vary.
  • The supplied token prices were benchmark inputs, not a promise of current provider pricing. Recheck prices before financial decisions.
  • The benchmark measures routing classification only. It does not claim that a correct label always selects the best downstream model.
